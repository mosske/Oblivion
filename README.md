# Oblivion - YouTube Music Web Client

A private YouTube Music web client built with React, Express, and TypeScript.

## Setup

1. Set `YOUTUBE_API_KEY` in Vercel environment variables
2. Set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`
3. Deploy

## Features

- Browse your YouTube playlists
- Search for music
- Trending recommendations
- OAuth authentication
